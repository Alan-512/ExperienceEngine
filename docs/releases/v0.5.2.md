# ExperienceEngine v0.5.2

**Status:** published to npm and GitHub Releases with annotated tag `v0.5.2`. The exact ClawHub archive attached to the GitHub Release passed controlled prepublication WSL acceptance. A later manual ClawHub upload created a public `0.5.2` entry, but that uploaded artifact is not the accepted reduced candidate: it contains only 49 files, omits the built runtime, and fails exact closure validation. Do not install the ClawHub `0.5.2` entry; use the `0.5.3` repair.

This patch release carries the privacy-safe diagnostics/public-feedback work and the Phase 0.5C residual benchmark evidence implementation needed to run a new exact-artifact OpenClaw campaign. It does not enable a general support claim or production learning readiness.

## Privacy-safe diagnostics and feedback

- Adds read-only `ee diagnose` over a strict allowlisted manifest.
- Adds review-first bundle preparation and deterministic one-file archive creation.
- Excludes prompts, source, paths, credentials, provider payloads, endpoints, raw settings/SQLite, and free-text errors by default.
- Adds public installation, runtime bug, harmful intervention, and feature-request templates without adding telemetry or automatic upload.
- Allows explicit feedback to bind to the latest actually delivered intervention when a real-host feedback turn has no persisted input record.
- Keeps skipped and otherwise undelivered interventions ineligible for fallback feedback attribution.

## Phase 0.5C benchmark evidence

- Adds the versioned decision-opportunity V2 ground-truth and arm-observation contracts while preserving retained V1 campaign scoring.
- Computes delivery, confusion, correct-skip, and false-positive evidence per predeclared decision opportunity.
- Adds causal harm-exposure/recovery-recheck evidence with authoritative production feedback and governance transitions.
- Adds sealed inject, correct-skip, and harm-recovery OpenClaw scenario adapters.
- Extracts common OpenClaw matched-block host execution without modifying retained v1-v4 campaign evidence.
- Requires formal execution to consume a previously sealed plan and reject artifact or host identity drift before creating the campaign database.
- Requires independent validation to read the exact artifact, observations, campaign SQLite, per-arm evidence, and retained runtime; reject duplicate/missing arms; and recompute the scorecard and publication decision.
- Adds a current-source local-pack feedback preflight that remains explicitly separate from exact published-artifact C3 evidence.

## Submission-review hardening

- Rejects unknown fields in sealed campaign plans, block plans, V2 arm observations, decision opportunities, and governance transitions even when an attacker recomputes outer digests.
- Binds runtime attribution and review row identities back to treatment arm evidence during independent validation.
- Requires exact artifact filename, byte size, SHA-256, model identity, executable identity, Node version, platform, and OpenClaw version before formal execution.

## Deterministic real-host command validation

- Registers an admin-scoped ExperienceEngine Gateway RPC method that dispatches directly through the loaded OpenClaw plugin into the package-local native runtime service.
- Removes conversational model output and assistant text formatting from native activation validation while retaining the separate real OpenClaw agent-turn requirement.
- Binds every command response to a one-time probe id, exact plugin id, exact native command name, requested operation, and strict runtime JSON envelope.
- Rejects natural-language responses, malformed envelopes, wrong plugin command identities, missing runtime JSON, and stale Gateway probe responses fail closed.
