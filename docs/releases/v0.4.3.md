# ExperienceEngine v0.4.3

`v0.4.3` is a patch release that preserves ExperienceEngine data continuity across host reinstall and repair flows.

## Fixes

- Codex and Claude Code installers now reuse a host's previously registered `EXPERIENCE_ENGINE_HOME` when the current process has no explicit home set.
- `ee repair codex` preserves the existing Codex ExperienceEngine home instead of rebuilding project hooks against the default user home.
- `ee doctor codex` and `ee doctor claude-code` now report ExperienceEngine home resolution, including the active home, default home, host-recorded home, and drift warning when applicable.
- Manual Codex MCP fallback documentation now clarifies that `$HOME/.experienceengine` is only the default example and should be replaced with an existing ExperienceEngine home when one exists.

## Notes

- This release does not migrate or merge existing SQLite data. If a user intentionally has multiple homes, choose the desired `EXPERIENCE_ENGINE_HOME` explicitly before running install or repair.
