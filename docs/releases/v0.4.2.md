# ExperienceEngine v0.4.2

`v0.4.2` is a patch release for host trace boundary validation and OpenClaw packaged-runtime stability.

## What Changed

- Fixed the OpenClaw packaged plugin bundle so static hybrid runtime imports required by `interaction/service.js` are included in copied extension installs.
- Hardened OpenClaw routine interaction hooks so an unexpected routine module shape cannot crash the lifecycle hook.
- Recorded cross-host source validation for runtime trace capture versus diagnostic full-trace persistence.

## Validation

- `pnpm typecheck`
- `pnpm test`
- `pnpm build`
- Real-host WSL validation for `Codex`, `Claude Code`, and `OpenClaw`
- Real-host OpenClaw diagnostic snapshot validation with `EXPERIENCE_ENGINE_TRACE_PERSIST_DIAGNOSTIC_SNAPSHOTS=true`
- Earlier Windows Antigravity trace boundary validation through the managed `ee agy exec` path

## Distribution Notes

- npm, GitHub release, and ClawHub publication should use `v0.4.2`.
- Source-repo host validation is recorded in `docs/development/source-repo-host-validation.md`.
- Published-package, GitHub release, and ClawHub validation still need to be performed after publication.
