# ExperienceEngine v0.4.6

This patch release fixes host install path handling for Claude Code and Codex.

## Fixes

- Normalize Windows paths embedded in Claude Code hook launchers so generated `node -e` hook commands survive Windows shell and Claude hook parsing.
- Ignore redacted Codex MCP environment values when preserving an existing ExperienceEngine home, preventing placeholder values from being written as real MCP paths.

## Validation

- `pnpm tsc --noEmit --pretty false`
- `pnpm test`
- `pnpm build`
- `npm pack --dry-run`
