# ExperienceEngine v0.3.4

Released: 2026-05-14

v0.3.4 adds learning-quality observability so users and operators can see whether ExperienceEngine is capturing useful project experience, rejecting low-value records, and closing the feedback loop on delivered guidance.

## Changes

- Added scope-level learning-quality metrics derived from existing task run, candidate, node, injection, and attribution records.
- Added candidate admission rate, captured/rejected/not-applicable counts, rejection reason distribution, generic/non-transferable rejection counts, and helped/harmed feedback closure counters.
- Added compact learning-quality output to `ee status` and `ee doctor <host>`.
- Kept the feature read-only: no database migration, no learning gate change, and no injection behavior change.
- Added a follow-up plan for Quality Band productization and Operator / Advanced surface consolidation.
