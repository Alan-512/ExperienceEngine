# ExperienceEngine v0.1.1

Release date: 2026-03-22

## Summary

`v0.1.1` upgrades ExperienceEngine's semantic retrieval stack from local-first embeddings to an API-first embedding pipeline with graceful local fallback.

This release focuses on retrieval quality, provider flexibility, and safer runtime behavior when remote embedding providers are unavailable.

## Included In This Release

### Embedding retrieval

- default embedding strategy is now `api`
- supported API embedding providers:
  - OpenAI `text-embedding-3-small`
  - Gemini `gemini-embedding-001`
  - Jina `jina-embeddings-v3`
- API embedding resolution order:
  - OpenAI when `OPENAI_API_KEY` is present
  - Gemini when `GEMINI_API_KEY` is present
  - Jina when `JINA_API_KEY` is present
- if no API provider is available, ExperienceEngine falls back to the managed local embedding model
- if local embeddings fail, ExperienceEngine falls back to legacy hash-based retrieval

### Retrieval behavior

- query and passage embeddings now use TTL/LRU runtime caches
- low-signal queries can skip semantic retrieval to reduce unnecessary remote calls
- transient embedding API failures retry once before fallback
- embedding failures now surface clearer diagnostics for auth, rate limit, timeout, and upstream errors

### Tooling

- new smoke command:

```bash
ee maintenance embedding-smoke
```

This measures:
- query cold / warm timings
- passage cold / warm timings
- the currently active embedding provider and model

## Configuration Notes

### New default

The default embedding mode is now:

```text
embeddingProvider = "api"
```

This is a behavioral change from `v0.1.0`, where embeddings were local-first by default.

### Force local embeddings

If you want to keep fully local embedding behavior:

```bash
export EXPERIENCE_ENGINE_EMBEDDING_PROVIDER=local
```

### Force a specific API provider

Use:

```bash
export EXPERIENCE_ENGINE_EMBEDDING_API_PROVIDER=openai
export EXPERIENCE_ENGINE_EMBEDDING_API_PROVIDER=gemini
export EXPERIENCE_ENGINE_EMBEDDING_API_PROVIDER=jina
```

### Required keys

- `OPENAI_API_KEY` enables OpenAI embeddings
- `GEMINI_API_KEY` enables Gemini embeddings
- `JINA_API_KEY` enables Jina embeddings

## Notes

- Gemini embeddings use `gemini-embedding-001`
- ExperienceEngine does not use a Gemini embedding fallback model in this release
- in environments without any API keys, the new default still degrades cleanly to the managed local model
