# ExperienceEngine v0.4.8

This working release note records the prompt-decision and status UX changes prepared after `v0.4.7`.

## Changes

- Extracted a shared `PromptDecisionPipeline` so lightweight shared-MCP prompt lookup and the full runtime prompt path use the same candidate loading, repo-policy evaluation, delivery suppression, scorecard, and `InjectionEvent` persistence logic.
- Extracted `TraceCaptureService` from the full runtime so trace normalization, trace provenance summaries, and opt-in diagnostic trace capsule persistence have an explicit runtime boundary without changing default narrow persistence behavior.
- Extracted `HybridPostmortemService` from the full runtime so async posttask review, provider fallback handling, artifact persistence, and accepted node review writeback are isolated behind a dedicated runtime boundary.
- Extracted `AttributionWritebackService` from the full runtime so automatic attribution rows, trajectory attribution metadata, record-only diagnostic rows, and shadow-probe quarantine writeback are isolated behind a dedicated runtime boundary.
- Extracted `InjectionOutcomeService` from the full runtime so injected-node feedback updates, injection event resolution, same-scope promotion, cross-scope portable validation evidence, and attribution writeback orchestration are isolated behind a dedicated runtime boundary.
- Added Antigravity to `ee status` installed-host and interaction-readiness reporting, matching the existing `ee doctor antigravity` support.
- Split `ee status` into a concise default progress view and a detailed `ee status --verbose` view.
- Personalized first-value next-step guidance with recent learning rejection reasons.
- Isolated explicit `homeDir` test/runtime paths from ambient `EXPERIENCE_ENGINE_HOME`, `EXPERIENCE_ENGINE_DATA_DIR`, and `EXPERIENCE_ENGINE_CAPTURE_DIR` values unless an env object is passed explicitly.
- Hardened slower Windows/SQLite test cases with explicit per-test timeouts so the full concurrent suite does not fail on default 5-second timing under load.
