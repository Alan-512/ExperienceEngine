# ExperienceEngine v0.4.5

`v0.4.5` is a patch release for LLM provider fallback reliability and first-run configuration.

## Fixes & Improvements

- Added a shared LLM request dispatcher so distillation, reranking, second-opinion checks, merge decisions, and hygiene planning use the same provider fallback behavior.
- Added `distillation.fallback_chain` and `distillation.fallback_codes` to `ee config get|set|unset`.
- Added fallback chain setup to `ee init distillation` and the interactive init wizard.
- Loaded shared `EXPERIENCE_ENGINE_FALLBACK_MODELS` secrets from the active ExperienceEngine home before OpenRouter requests, so Codex/OpenClaw/Claude Code can reuse the same fallback model list.
- Normalized comma-list CLI values that Windows PowerShell may pass as whitespace-separated arguments.
- Documented the difference between ExperienceEngine cross-provider fallback and OpenRouter's same-request fallback models.

## Upgrade Guide

```bash
npm install -g @alan512/experienceengine@latest
ee config set distillation.fallback_chain "gemini:gemini-2.5-flash,openai:gpt-4o-mini"
ee config set distillation.fallback_codes "429,500,502,503,504"
```
