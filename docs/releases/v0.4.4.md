# ExperienceEngine v0.4.4

`v0.4.4` is a feature release that migrates both the **Claude Code** and **Codex** adapters from project-local setups to **global/user-level defaults**, aligning them with the seamless out-of-the-box experience of OpenClaw and Google Antigravity.

## Features & Improvements

### 1. Claude Code Global Settings & MCP Integration
- Refactored the installer to write Claude hook configurations directly into the global user settings file `~/.claude/settings.json`.
- Registers the ExperienceEngine MCP server globally (`-s user` mode) for immediate availability across all project workspaces.
- Automatically cleans up and prunes duplicate project-local `.claude/settings.local.json` and `.mcp.json` files to prevent configuration drift and repository pollution.
- Dynamically resolves Marketplace plugin conflicts by safely disabling local execution overlaps.

### 2. Codex User-Level Hooks & TOML Config
- Redirects Codex lifecycle hooks (`UserPromptSubmit`, `PostToolUse`, `Stop`) to the user's global configuration file `~/.codex/hooks.json`.
- Programmatically integrates with `~/.codex/config.toml` to safely toggle `hooks = true` inside the features block.
- Deletes obsolete project-local `.codex/hooks.json` files and Windows `.cmd` launcher files from git-tracked workspace roots.

### 3. Dynamic Scope Isolation & Zero Crosstalk
- Guarantees strict workspace experience isolation through dynamic project root resolution. Upon receiving a hook event, the engine walks up the active directory (`cwd`) to locate the Git root, hashes it, and queries SQLite under isolated `scope_id` boundaries.
- Resolves cross-platform path mount variations (mapping POSIX mount paths like `/mnt/d/` to their Windows drive equivalent `d:/`), ensuring identical `scope_id` hashes whether the agent is executed in Windows PowerShell or a WSL Linux container.

### 4. Robust Cross-Runtime Node Wrappers
- Integrates transparent platform detection (`process.platform === 'win32'`) inside inline Node.js execution wrappers.
- Allows co-existing Windows IDE host environments and WSL CLI environments to trigger global hooks cleanly without directory mount errors or absolute path crashes.

## Upgrade Guide

To upgrade the global hooks setup, simply pull the latest package version and run the installer commands:

```bash
# Upgrade Claude Code integration
ee install claude-code

# Upgrade Codex integration
ee install codex
```
