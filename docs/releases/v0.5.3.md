# ExperienceEngine v0.5.3

**Status:** authorized three-channel repair candidate. Publish only after the exact npm and reduced ClawHub artifacts are generated from a clean source commit and pass the complete release gate.

This patch release repairs the invalid public ClawHub `0.5.2` artifact while preserving the accepted npm `0.5.2` runtime and Phase 0.5B/0.5C evidence boundaries. It does not enable a general support claim or production-learning readiness.

## ClawHub artifact repair

- Publishes the reduced OpenClaw runtime artifact generated by `release:build-candidates`, not a source-only root `npm pack` archive.
- Requires the built OpenClaw plugin entrypoint, CLI entrypoint, embedded runtime closure manifest, package/plugin manifests, and bundled runtime dependencies before a ClawHub candidate can be accepted.
- Keeps dev dependencies out of the reduced ClawHub artifact and regenerates package build/profile/closure identity after dependency pruning.
- Requires an independent public ClawHub reverse-download and exact closure/runtime validation after publication.

## Claude marketplace version repair

- Aligns both Claude plugin manifests and the marketplace bootstrap installer with package version `0.5.3`.
- Ensures the installer cache stamp and persisted marketplace state report the same exact version that is installed.
- Adds regression tests that compare every Claude marketplace version authority with root `package.json` instead of hardcoding a stale plugin version.

## Trust-boundary disclosure

- States prominently that lifecycle hooks can observe prompt, tool, failure, and session events.
- Documents persistent user-level host configuration and product state across later sessions/workspaces.
- Distinguishes metadata-only normal trace persistence from opt-in raw OpenClaw payload capture.
- Warns that raw captures may contain prompts, tool data, secrets, personal data, or proprietary content.
- Warns that configured remote embedding/model providers receive selected task content under the provider's data-handling policy.

## Preserved evidence boundary

- Accepted npm `0.5.2` diagnostics and multi-scenario campaign evidence remains historical exact-artifact evidence and is not rewritten as `0.5.3` efficacy evidence.
- The invalid public ClawHub `0.5.2` artifact is not accepted channel evidence and must not be installed.
- `support_claim_allowed=false` and `production_learning_ready=false` remain required.
