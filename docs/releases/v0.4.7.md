# ExperienceEngine v0.4.7

This patch release fixes Codex lifecycle installation and diagnostics on Windows.

## Fixes

- Run Codex CLI management commands through `cmd.exe` on Windows so npm command shims work with `ee install codex`, `ee upgrade codex`, and `ee doctor codex` instead of failing with `EPERM` or reporting false host-wiring drift.
- Add a Windows-specific Codex hook command that invokes the managed `.cmd` launcher while preserving the cross-runtime command for POSIX hosts.
- Inspect and replace stale ExperienceEngine hook entries across both the default and Windows-specific command fields.

## Upgrade Guide

```powershell
npm install -g @alan512/experienceengine@0.4.7
ee upgrade codex --runtime-target windows --hooks
```

Review the refreshed `UserPromptSubmit`, `PostToolUse`, and `Stop` hooks with `/hooks` in Codex after upgrading.
